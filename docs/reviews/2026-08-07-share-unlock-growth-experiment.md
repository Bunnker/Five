# Five 未来内容分享解锁实验规格

状态：研究提案，不进入本轮代码
日期：2026-08-07
依据：大师提出、维护者转述的“今天、明天免费，未来三天通过传播贡献解锁”设想。该设想尚未立项，本文仅作研究记录，不代表已批准产品范围。

## 结论

本轮不开发积分、推荐码、分享归因、未来内容锁、账号体系、权益表或防刷系统。

Five 当前最重要的产品资产，是用户每天愿意回来相信并使用一次穿衣建议。分享机制只有在证明“未来内容确有提前查看价值”且不会损害信任和留存后，才值得进入独立开发阶段。

## 需要验证的假设

核心假设：普通用户会因出行、约会、工作安排等真实需要，希望提前查看未来三天的颜色和穿搭，并愿意自然地把 Five 分享给别人。

以下任一结果都构成反证：

- 用户很少点击未来日期，说明提前查看价值不足；
- 用户打开分享入口后很少回来查看，说明行为主要是任务驱动；
- 今日或明日的访问、完成阅读或七日回访下降；
- 用户反馈出现“强制分享”“内容被扣住”或对大师内容可信度的质疑；
- 只能靠夸大奖励、虚假积分或无法验证的转发人数维持转化。

## 分阶段最小实验

### 阶段 0：只验证需求，不锁内容

在不改变今天和明天体验的前提下，对小流量用户展示“未来三天提前参考”入口。点击后说明该能力尚在测试，并收集一个可选原因：出行安排、重要场合、日常备衣或其他。

这一阶段不要求分享，也不授予权益。先回答“用户是否真的想看”，避免先建增长系统再寻找需求。

建议至少观察两周或 500 个符合条件的匿名会话，再决定是否进入下一阶段。

### 后续候选阶段 1：匿名短期解锁（须独立立项，当前未批准、未开发）

只有阶段 0 证明需求后，才对不超过 10% 的稳定随机样本测试：今天和明天始终免费；未来三天入口可通过一次明确的分享意图获得当前浏览器的短期预览。

网页和微信环境通常不能可靠知道用户是否真正发送、发送给谁或触达多少人。因此只能记录“打开了分享入口/系统分享面板并返回”，不得在界面或数据中称为“成功邀请”或“有效转发”。这种信号可以用于低风险产品实验，不能作为永久权益、积分或商业结算依据。

若未来确需验证真实传播，可以单独研究带匿名短链接的入站访问，但必须重新评估微信能力、隐私、延迟解锁、刷量和用户体验；不属于当前实验。

## 实验分组

- A 组：现有体验，不显示分享解锁；
- B 组：阶段 0 的未来内容需求入口；
- C 组：仅在阶段 0 成立后启用，测试匿名短期解锁。

分组由服务端稳定决定，不使用浏览器随机数，不根据用户设备时间判断业务日期。任何实验都不能改变北京时间 18:00 的公开内容窗口或 23:00 的命理日规则。

## 成功指标与停止条件

主指标：获得未来预览后 7 日回访率相对对照组不下降。

辅助漏斗：

1. 符合条件会话中的未来日期点击率；
2. 未来日期点击后的分享入口点击率；
3. 分享入口返回后的未来内容查看率；
4. 未来内容实际阅读完成率；
5. 今日、明日内容的阅读完成率与次日、七日回访；
6. 与“强制分享、无法解锁、隐私、内容可信”有关的反馈率。

进入开发前应预先冻结样本量和阈值。首轮建议的保护线：实验组 D7 留存相对对照组下降超过 2 个百分点、今日阅读完成率下降超过 3%、相关负反馈超过符合条件会话的 0.5%，或出现无法安全关闭/回退的故障时立即停止。阈值只是实验决策线，不是长期业务目标。

## 无账号能力边界

可以使用：服务端生成的随机匿名实验标识、稳定分组、短期服务端会话和带签名的匿名解锁凭证。

不承诺：跨设备、跨浏览器、永久权益、成长等级、家庭共享或历史积分。不得用持久设备指纹弥补没有账号的问题。

如果进入阶段 1，匿名解锁只对当前浏览器生效，最长 72 小时，并允许服务端随时关闭。过期后自然回到今天和明天免费状态，不产生可累计余额。

## 隐私与反作弊

最少记录：匿名实验标识、实验组、公开内容日期、分享意图时间、解锁时间、过期时间和未来内容访问时间。

禁止收集：通讯录、微信好友、分享对象身份、群信息、精确位置、社交关系或用于长期识别的设备指纹。

第一阶段只做低成本保护：同一匿名会话限频、服务端签名、防止重复领取、异常高频告警。不要提前建设积分风控、排行榜或推荐关系图。

## 微信与网页限制

- 不假设网页能读取转发人数、收件人或群信息；
- 不把分享面板打开事件当成真实传播结果；
- 分享能力不可用、用户取消或回调缺失时，今天和明天仍可正常使用；
- 文案必须说明这是“提前查看未来安排”的实验，不能使用诱导、倒计时、好友助力或虚假成功提示；
- 分享落地页仍读取真实已发布内容，不引入 demo 数据或另一套日期规则。

## 事件草案

- `future_preview_interest_viewed`：看到未来三天入口；
- `future_preview_interest_clicked`：主动点击入口；
- `future_preview_reason_selected`：可选需求原因；
- `share_intent_opened`：打开分享入口或系统面板；
- `share_intent_returned`：返回 Five，仅表示意图链路完成；
- `future_preview_unlocked`：匿名短期凭证签发；
- `future_preview_used`：实际查看某个未来日期；
- `growth_experiment_feedback_submitted`：提交相关反馈。

所有事件使用服务端时间和公开内容日期；不得记录分享对象，也不得把 `share_intent_returned` 命名为成功邀请。

## 失败降级与退出

实验服务、分享能力或事件采集异常时，核心公开页继续正常工作。今天和明天不能被锁。关闭实验后所有用户直接回到基线体验，不需要迁移积分、账户或用户关系数据。

## 后续立项门槛

只有同时满足以下条件，才准备独立 Issue、PRD、隐私评审和接口设计：

1. 阶段 0 证明未来三天存在稳定需求；
2. 小流量实验没有伤害今日/明日完成率和七日回访；
3. 用户不把机制理解为强制分享或内容降级；
4. 微信与普通浏览器的能力边界已用真实环境验证；
5. 事件、关闭开关、匿名凭证和失败降级都能独立验收。

在这些门槛满足前，本规格只作为研究记录，不修改 Five 当前产品范围。
