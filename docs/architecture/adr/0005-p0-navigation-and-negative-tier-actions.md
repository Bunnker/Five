# ADR-0005：P0 首页、导航与负向档交互

- 状态：Accepted
- 日期：2026-07-23

## 背景

探索原型包含多个首页方向、底部 Tab、历史图标、出生信息和 P1/P2 入口，与 P0 的“十秒完成今日穿衣决策”目标及范围边界冲突。F02 又为所有档位放置箭头，但较差和不利档没有对应搭配详情。

## 决策

1. 首页采用唯一的决策优先结构：前三档展开，较差与不利合并为紧凑摘要。
2. 首页在颜色决策之后展示“今日怎么搭”和 1 主 2 备模特入口。
3. P0 不使用底部固定 Tab，不提供“我的”、生肖、出生信息、个人五行、收藏、拍照试搭或历史浏览入口。
4. `/daily/{fortuneDate}` 只服务分享落地和既有日期链接解析。
5. F02 仅大吉、次吉、平显示“查看穿法”；较差和不利只显示减少说明，不显示无目标箭头。

## 影响

- 现有原型不能直接作为开发视觉基线；
- H5 与小程序可使用不同导航外观，但页面层级一致；
- P1/P2 原型单独归档，不进入 P0 任务；
- 页面骨架可以在正式高保真设计完成前按固定数据并行开发。
