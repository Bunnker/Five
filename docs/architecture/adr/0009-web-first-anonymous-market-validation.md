# ADR-0009：P0 采用匿名网页完成市场验证

- 状态：Accepted
- 日期：2026-07-26
- 替代：ADR-0001、ADR-0007

## 背景

Five 当前最重要的目标是验证用户是否愿意从微信群打开每日五行穿搭内容并持续使用，而不是同时验证微信小程序、账户体系、在线交易或大师服务平台。继续按 H5 与微信小程序双端建设，会在市场验证前引入平台审核、跨端适配和额外运维成本。

## 决策

P0 只交付响应式公共网页。运营者或大师把一个 HTTPS 链接人工发送到微信群，用户匿名打开并浏览内容；产品不接入微信群、不代替人工发送，也不建设大师渠道系统。

P0 不开发微信小程序和原生 App，不要求登录，不创建用户档案，不收集出生信息，不提供在线大师咨询，不接在线支付。后续是否建设 App 根据网页阶段的访问、回访和内容反馈另行立项；微信小程序不再是当前开发或发布门槛。

网页可以使用美国区域的基础设施进行受控市场验证，但必须在真实中国大陆微信内置浏览器和不同网络环境完成访问测试。服务器位置不改变面向中国大陆用户时适用的内容与个人信息合规义务。

## 影响

- ADR-0001 的双端首发范围和 ADR-0007 的 Taro 双端方案不再是开发基线；
- ADR-0008 的 TypeScript 模块化单体与 PostgreSQL 后端方案继续有效；
- 客户端只需针对现代移动浏览器与微信内置浏览器交付，不为尚未立项的客户端提前抽象跨端运行时；
- 公共 API、内容版本和领域模型保持平台中立，为未来 App 提供复用边界；
- P0 的市场验证指标聚焦网页打开、核心内容阅读、页面回访和用户反馈，不把微信群发送结果或大师渠道自动化计入产品能力；
- PRD 中“双端首发”、小程序分享、小程序码和双端一致性条款需要在进入任务拆分前同步修订；
- 若重新启动微信小程序或 App，必须新增 ADR 说明客户端技术栈、分发渠道和与公共内容域的集成方式。
