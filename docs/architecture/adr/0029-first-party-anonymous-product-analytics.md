# ADR-0029：第一方匿名产品统计与可观测边界

- 状态：Accepted
- 日期：2026-08-09
- 保留决定：ADR-0009 的匿名网页验证、ADR-0017 的 OpenAPI 契约事实源、ADR-0027 的单一维护者后台信息架构、ADR-0028 的 18:00 公开切换与 23:00 命理日边界

## 背景

Five 需要验证普通用户是否真的打开每日内容、查看穿搭并主动分享。只依靠维护者口头反馈无法区分页面被访问、内容被使用和分享带来回流；但 P0 又明确不建立账号、用户档案或跨设备身份，也不能把浏览器能够观察到的“点击分享”夸大成微信实际发送成功。

统计属于旁路能力。它失效时不能阻止 `/today`、搭配查看、页面跳转、系统分享、复制链接或海报保存，也不能把后台的内容运营读模型变成分析系统的依赖方。

## 决策

### 第一方匿名事件

1. Five 只使用自己的 `POST /api/v1/analytics-events` 接收 P0 事件，不接入第三方分析 SDK，不加载第三方追踪脚本。
2. 事件只允许冻结枚举及严格字段：`eventId`、`eventName`、`fortuneDate`、`contentVersion`、`channelId`、`anonymousId`、可空的 `referralId` 与 `posterInstanceId`。服务端拒绝未声明属性。
3. `fortuneDate` 与 `contentVersion` 必须来自服务端实际交付的公开内容，浏览器不得根据设备时间推断业务日期。北京时间 18:00 切换时，事件跟随 `servedFortuneDate` 对应的真实内容；23:00 不重复切换统计日期。
4. 浏览器使用高熵随机 `eventId` 保证一次行为的幂等重试。服务端以 `eventId + 规范化请求摘要` 判断：相同载荷重放记为 duplicate，不重复统计；不同载荷复用同一 ID 返回冲突。
5. 埋点必须 fire-and-forget。客户端可以使用 `sendBeacon` 或 `fetch(..., { keepalive: true })`，但不得等待统计请求后才执行用户动作；任何统计错误都由统计边界吞掉。

### 匿名标识、回流与隐私

6. `anonymousId` 只代表当前浏览器的随机第一方标识，不代表真实个人、设备指纹或跨设备用户。服务端只保存使用 Five 独立密钥计算的 HMAC 摘要，不保存原始值。
7. `referralId` 每次分享单独随机生成并放入分享 URL，只用于关联分享回流。它不得包含或复用 `anonymousId`，不得记录联系人、群、分享目标或平台账号。
8. Five 不保存分析事件的 IP、完整 User-Agent、Referrer、完整 URL、联系人、群或分享目标；公开分享链接不得携带原始匿名浏览器标识。
9. 原始事件保存 90 日，到期后删除。公开帮助页必须在启用统计前说明用途、口径、期限和退出方法；用户退出后停止创建及发送事件，并可清除本机匿名标识。

### 可报告的事实

10. 后台通过受管理员会话保护的 `GET /admin/api/v1/analytics/overview` 读取最多 31 个 `fortuneDate` 的摘要；响应使用 `no-store`，分析读取失败只影响统计卡，不影响内容运营页。
11. P0 展示 PV、匿名浏览器数、搭配查看人数与查看率、分享发起次数与人数、分享链接或海报带来的回流人数，以及海报保存请求/成功/失败的可观察结果。
12. “分享发起”表示用户触发了系统分享或对应降级入口，不表示微信、朋友圈、QQ 等平台实际发送成功。“回流”只表示带 `referralId` 的页面后来被打开。“匿名浏览器”不得写成真实用户数。
13. 比率必须同时返回分子、分母和可空结果；分母为零时返回 `null`，界面显示暂无样本，不用 `0%` 冒充已经完成采集。

## 结果

- Five 能在不建立账户画像的前提下验证“打开 → 查看搭配 → 发起分享 → 带来回流”的最小增长漏斗。
- 分析系统与核心内容交付解耦；统计故障不会让用户无法查看或分享内容。
- 单一维护者能在“今日”页看到可理解的使用情况，一级导航仍保持“今日、日历、异常”。
- 因为浏览器和普通 H5 无法观测微信最终发送结果，任何平台级成功率都必须等待平台正式能力和新的事实源，不能从点击行为推断。

## 必测边界

- 相同事件并发重试只保存一次，不同载荷复用 ID 返回冲突；
- 数据库不保存原始 `anonymousId`、IP、User-Agent、Referrer 或完整 URL；
- 17:59 至 18:00 的事件使用服务端已交付内容日期，22:59 至 23:00 不重复推进；
- 分享取消或平台失败仍只保留“发起”，不得产生“发送成功”事件；
- 带独立 `referralId` 的普通链接与海报落地可以形成回流，不暴露发送者匿名标识；
- 管理员摘要必须认证、`no-store`、最多 31 日且分母为零时比率为 `null`；
- 退出统计后不创建匿名标识、不发送事件，清除本地数据不会擅自重新启用统计；
- 事件接口不可用时，页面、搭配、系统分享和海报操作继续执行。

## 未采用方案

- **接入第三方埋点 SDK**：增加外部追踪与合规面，P0 不需要，拒绝采用。
- **使用 IP 或设备指纹估算用户**：超出匿名验证所需范围，且不能形成可靠真实用户身份，拒绝采用。
- **把 `anonymousId` 放进分享链接**：会泄露发送者的持久浏览器标识，拒绝采用。
- **把系统分享回调当作微信发送成功**：普通网页无法获得该事实，拒绝采用。
- **统计请求失败时阻断主流程**：会让旁路能力降低核心体验，拒绝采用。
