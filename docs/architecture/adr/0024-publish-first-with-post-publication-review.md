# ADR-0024：自动内容先发布、后检查

- 状态：Accepted
- 日期：2026-08-03
- 取代：ADR-0011、ADR-0015、ADR-0023 中“大师确认、人工图片检查和发布预检属于上线前强制门槛”的决定

## 背景

Five 的当前目标是尽快让用户端看到系统自动生成的真实每日内容。维护者确认，本地验证阶段不再等待大师确认、图片人工检查、权利材料、AI 标识或完整预检后才发布；大师需要直接查看每天的用户端效果，发现问题后再修改。

## 决策

1. 自动生成的每日文字、穿搭和至少两张图片候选形成不可变内容版本后，直接发布或按命理日生效时间排期。
2. 大师确认、图片检查、权利材料、AI 标识和海报检查保留为发布后记录，不阻止首次发布或替换发布。
3. “直接修改”不覆盖用户已经看过的内容。维护者从当前版本复制新草稿，冻结成新 `contentVersion` 后原子替换 `ActiveVersion`；旧版本进入 `superseded`。
4. 同一命理日仍只有一个活跃版本；发布、替换、下线、恢复、单图停用、缓存清理、审计、并发保护和幂等规则继续生效。
5. 日历算法仍由确定性规则和 366 日机器答案约束，生成模型不得修改干支、五档或颜色归行。
6. 这项决定先服务本地产品验证，不代表图片权利、AI 标识、部署、协议或真实网络等公网试用条件已经满足。

## 影响

- 草稿提交后直接进入 `approved`，不再以 `in_review` 作为默认停留状态。
- 发布接口仍返回预检结果供后台展示，但预检失败不再阻止首次发布和排期。
- 大师依据允许在 `approved`、`scheduled`、`published` 或 `superseded` 版本上补充登记。
- 后台以用户端视觉预览、当前活跃版本和“复制修改并替换”为主要操作，不再把 JSON 和批准表单作为主流程。
