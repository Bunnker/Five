# ADR-0001：H5 与微信小程序共享一个内容域

- 状态：Superseded by ADR-0009
- 日期：2026-07-23

## 背景

Five 的 P0 同时发布移动端 H5 和微信小程序。若两端分别实现日期、五行、内容版本和发布逻辑，容易在 23:00 跨日、回滚和分享落地时产生结果漂移。

## 决策

两端共享服务端算法、公共 API、内容快照、活跃版本和 `contentVersion`。导航、分享、入口码、权限、本地存储和发布流程根据渠道能力分别适配，不为了前端代码复用强行绑定某一跨端框架。

## 影响

- 日柱、五行、五档、颜色和内容版本只能由同一服务端规则提供；
- 两端需要共用黄金数据和跨日验收用例；
- UI 可以不同，但业务结果和页面层级必须一致；
- 渠道适配代码不得复制或覆盖业务算法。
