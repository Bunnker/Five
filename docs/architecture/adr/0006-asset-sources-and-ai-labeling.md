# ADR-0006：素材来源与 AI 标识

- 状态：Accepted
- 日期：2026-07-23

## 背景

P0 需要稳定提供与文字配方一致的模特穿搭图片。授权素材库和 AI 生成各有质量、成本、权利与审核差异，但这些差异不应迫使业务数据模型只支持一种来源。

## 决策

1. 素材模型同时支持授权素材、AI 生成素材和审核过的降级模板。
2. P0 不建设完整的内置图像生成平台；允许外部生成或选图后人工上传。
3. 所有正式制品记录 `assetSourceType`、素材哈希、权利证明、审核结果和 AI 标识状态。
4. AI 生成素材另记录模型、提示词版本和随机种子或等价重现信息。
5. AI 内容按适用法律、强制标准和平台规则落实显式标识、隐式标识及下载/导出保留要求。
6. 首批主管线在正式批量生产前，以样张质量、稳定性、权利证明、成本和平台审核结果共同决定。

## 影响

- 后台审核和公共 API 可以先按统一素材抽象开发；
- 主管线选择不阻塞页面、内容模型和小批量验证；
- 批量内容投产前必须完成权利与标识 SOP；
- 图片失败时必须回退到审核过的模板或纯色单品板。
