# ADR-0016：提前批量生成每日图片，Codex 为主、中转为备用

- 状态：Superseded by ADR-0023
- 日期：2026-07-26
- 补充：ADR-0006、ADR-0013

## 背景

Five 网页验证版每天需要 2 至 3 张与当日颜色和搭配建议一致的图片。用户打开网页时才临时生图，会带来等待、失败、重复扣费和未经检查的图片直接展示等问题，也会增加一人维护的难度。

维护者可以在开发和内容准备阶段使用 Codex 提前生成图片，也已经有一个在 Redar 项目中实际使用过的 GPT Image 2 中转服务。前者适合受控的小批量准备，后者可以在 Codex 额度不足或暂时不可用时补充，但中转服务以后可能更换。

## 决策

P0 使用“上线前提前生成、人工检查后上传”的方式准备图片：

1. 主管线是在维护者自己的开发环境中使用 Codex 和 GPT Image 2，按明确日期分批生成；
2. Codex 额度不足或暂时不可用时，才使用 Redar 已验证过的中转接口作为备用；
3. Five 网站、后台和公开服务器都不负责生图，也不在服务器上部署 Codex；
4. 用户访问网页时，只读取已经生成、检查并上传完成的图片；
5. 中转地址、模型名称和密钥必须可以单独配置。Five 使用自己的密钥和费用上限，不复用 Redar 的密钥；以后更换中转服务时，不改变内容和图片的业务结构；
6. 图片经过检查后上传到自己控制的图片存储，再由网页读取。具体图片存储和内容加速服务随美国部署方案另行确认，正式环境不能只把图片放在代码仓库或应用服务器本地磁盘。

每个命理日的图片数量和用途固定为：

1. 必备主图：以当日大吉色为主要颜色的完整穿搭；
2. 必备备选图：以大吉色和次吉色组成的另一套穿搭；
3. 可选补充图：大吉色与平色的组合，或者适用于另一场景的穿搭。质量不够时可以不提供，不放空白占位图。

正常发布时，每天必须有前两张通过检查的图片。图片上线后如果发现质量、版权或标识问题，应立即停止使用问题图片，并临时切换到 ADR-0013 规定的已审核配色卡片或纯色单品板；不能因为图片下线而让正确的日期、五行和文字内容无法访问。

图片生产按阶段扩大：

1. 先准备约 30 天，每天 2 张必备、第 3 张可选，约 60 至 90 张；
2. 由维护者逐张检查，并让大师确认首批图片的整体方向和搭配是否可用；
3. 首批验证通过后，再按季度准备；市场反馈稳定且额度允许时，才扩大到一年；
4. 不启动没有数量上限、没有人工检查的长期自动生成任务。

每张图片至少记录所属 `fortuneDate`、`contentVersion`、图片位置和文件校验值、生成方式（Codex 或中转）、当时声明的模型、提示词版本、生成时间、人工检查记录、权利材料以及 AI 标识状态。分享海报从这些已通过检查的图片和海报模板生成，不额外调用 AI 生图。

## 影响

- 首版不需要建设生图接口、任务队列、失败重试、在线计费或服务器上的 Codex 环境；
- 用户访问速度和页面可用性不依赖 Codex 或中转服务当时是否正常；
- 维护者需要提前安排每月图片准备和逐张检查；
- 中转服务只是可替换的备用能力，不能成为 Five 网站运行的必要条件；
- 公开试用前仍需完成图片存储、AI 标识、权利材料、压缩和下线替换的实际验收；
- 本轮只记录方案，不生成图片、不调用付费生图服务，也不部署图片。
