# ADR-0014：公开保留吉档名称并用配饰给出平衡建议

- 状态：Accepted
- 日期：2026-07-26
- 补充：ADR-0005

## 背景

Five 的首批用户熟悉并重视“大吉、次吉”等传统名称。完全改成普通穿搭用语会削弱产品辨识度和传播吸引力；直接突出“较差、不利”，又容易让已经穿了这些颜色的用户感到焦虑，而且没有告诉用户接下来可以做什么。

## 决策

公开网页和分享海报优先展示“大吉、次吉、平”三个名称，同时分别补充“今日优先、稳妥选择、日常可穿”等容易理解的说明。

内部计算继续保留“大吉、次吉、平、较差、不利”五档。公开页面把“较差”和“不利”合并为一个紧凑的“注意”区域，不用警报样式，也不使用恐吓文案。

如果用户已经穿了“注意”范围内的颜色，页面提供平衡建议：选择当日大吉色的普通配饰进行小面积补充，例如围巾、包、鞋、帽子、腰带或首饰。建议说明这是当天五行配色的补充方法，不承诺改变个人财运、健康或事情结果。

首版不推荐吉祥物，不提供商品购买链接、订单、支付或收款功能。较差和不利档仍不进入完整穿搭详情，平衡建议直接在“注意”区域展示。

## 影响

- 页面和海报要同时保留传统名称与容易理解的穿搭说明；
- 后台和公共接口仍保存完整五档结果，不能因为公开页面合并显示而改变算法；
- 内容后台需要为“注意”区域填写或选择大吉色配饰建议；
- P0 不需要吉祥物清单、商品库、购物链接、订单或支付功能；
- PRD 中“较差和不利只显示减少说明”的规则，需要补充为“减少说明 + 大吉色配饰平衡建议”。
