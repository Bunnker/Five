# ADR-0017：OpenAPI 是网页、后台和后端接口的唯一事实源

- 状态：Accepted
- 日期：2026-07-26
- 补充：ADR-0003、ADR-0004、ADR-0009、ADR-0015

## 背景

PRD V2.3 已经写出今日内容、指定命理日、穿搭详情和后台生命周期的大体接口，但字段散落在正文和示例中。后续网页、后台、HTTP 进程和 Worker 如果各自写类型，容易出现内容状态、图片字段、错误码和版本冲突处理不一致。旧示例还保留只为 H5 与小程序双端准备的 `platform`、`sourcePlatform` 和 `targetPlatform`。

## 决策

`docs/api/openapi.yaml` 是 P0 HTTP 接口的唯一事实源。网页和后台从它生成类型，后端按它实现请求、响应和错误，契约检查直接验证这份文件。

公开接口只返回已经发布且允许公开的内容。后台接口可以读取草稿、不可变快照、检查结果、大师确认依据和审计记录，但必须经过安全会话。登录、二次确认、找回和紧急控制的具体接口仍由 Issue #31 确认，本 ADR 不提前决定。

`contentVersion` 和所有业务 ID 都是不可解析的不透明值。网页使用 `contentVersion` 防止拼接新旧内容；后台草稿和内容生命周期分别使用自己的 ETag 与 `If-Match`；提交草稿和所有状态变化还必须使用 `Idempotency-Key`。网页版本变化、后台修订号变化和活跃内容版本变化使用不同错误码。

P0 只有网页端，不再传 `platform`、`sourcePlatform` 或 `targetPlatform`。需要区分普通链接、海报或其他分发来源时只传 `channelId`，且该字段不得改变正文、日期、档位或图片。

公开图片字段与后台图片字段分开。公开端只得到展示所需的 URL、尺寸、格式、替代文字和 AI 说明；后台额外保存文件校验值、来源类型、声明模型、提示词版本、人工检查、权利记录和 AI 标识状态。

## 影响

- PRD 继续解释产品目标和业务规则，但不再作为字段级接口事实源；
- 任何接口字段、枚举、错误码或示例变化先修改 OpenAPI，再生成类型并调整实现；
- 网页不需要知道 PostgreSQL、图片存储供应商、任务领取方式或内容内部模块如何实现；
- 将来重新开发小程序或 App 时，必须新增明确的客户端和渠道契约，不能把双端字段悄悄塞回 P0 接口；
- `/api/v1` 对外使用后，破坏兼容性的修改需要新增接口版本。
