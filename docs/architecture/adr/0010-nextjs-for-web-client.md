# ADR-0010：网页端采用 Next.js、React 与 TypeScript

- 状态：Accepted
- 日期：2026-07-26

## 背景

ADR-0009 已把 P0 收敛为一个在微信群中人工分发的匿名公共网页，不再需要同时编译微信小程序。继续使用以小程序规范为中心的跨端框架不能带来当前阶段的直接收益，反而会限制标准 Web 渲染、分享元数据和后续网页获客能力。

## 决策

P0 网页端使用 Next.js、React 与 TypeScript，优先保证移动浏览器与微信内置浏览器体验。页面从公共 API 获取服务端确认的 `requestContext` 和内容版本；网页端不实现日历、五行或内容状态机规则。

P0 不为了未来 App 共享页面运行时。未来 App 若立项，默认评估 Expo 与 React Native，并只共享 OpenAPI 生成类型、领域值对象、设计令牌和无平台依赖的展示规则；具体选择必须另行形成 ADR。

## 影响

- `/today` 与 `/daily/{fortuneDate}` 可以使用服务端渲染或服务端生成分享元数据，但业务内容仍以公共 API 和活跃版本为事实源；
- 微信内置浏览器、iOS Safari 和 Android 主流浏览器属于 P0 真机验收范围；
- 公开页面必须提供稳定 HTTPS URL，并避免依赖微信小程序能力；
- 网页部署必须支持按环境配置 API 地址、图片域名、缓存响应头和可观测性；
- 不为尚未立项的 App 引入跨端组件约束，也不复制服务端算法；
- ADR-0007 保留为历史记录，不再影响依赖选择和页面实现。
