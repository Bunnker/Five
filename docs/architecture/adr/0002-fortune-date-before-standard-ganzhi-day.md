# ADR-0002：先得到命理日，再计算标准干支日

- 状态：Accepted
- 日期：2026-07-23

## 背景

Five 采用北京时间 23:00 进入下一命理日的产品规则。如果直接把宿主设备时间交给日历库，可能重复应用换日逻辑，并让不同进程时区得到不同结果。

## 决策

先按 `Asia/Shanghai` 与 `dayBoundary = 23:00` 得到唯一的 `fortuneDate`，再依据 GB/T 33661-2017 的六十干支周和 1949-10-01 甲子日基准计算日干支。P0 不把外部黄历 API 作为在线真相源；固定版本离线农历库只用于展示扩展和独立交叉验证。

## 影响

- `fortuneDate` 在一次请求中只能平移一次；
- 核心计算封装为无网络依赖的 `CalendarRuleEngine`；
- 所有语言实现必须通过同一套 366 日黄金数据和边界测试；
- 规则变化必须升级 `calendarRuleVersion`。
