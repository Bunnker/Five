# Triage 标签

工程技能使用五种标准 Triage 角色。下表将这些角色映射到本仓库 GitHub Issues 中的实际标签。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估和分类 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给自主 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类开发者处理 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到某个 Triage 角色时，使用上表对应的标签字符串。

如需更换 GitHub 中的标签命名，只修改右侧“本仓库标签”列，并同步更新远程标签。
