# Issue #35 浏览器验收证据

验收时间：2026-07-29（Asia/Shanghai）

## 环境

- Next.js 生产构建：`pnpm --filter @five/web build`
- Open Design 0.16.1：项目 `five-prototype-v2-alignment`，成功运行 `a1d0e8f9-c48f-4827-8761-e2b66ceea0fc`
- 浏览器：Playwright CLI 驱动 macOS Chrome 150.0.0.0
- 浏览器视口：375 × 812；补充窄屏检查：320 × 700
- 公开数据：本地后端返回的当前已发布演示内容，页面未使用原型占位结果

## 结果

- 首页 `scrollWidth` 为 375px，无页面级横向滚动；日期与三档颜色的底部为 563px，“注意”从 571px 开始并在 851px 结束，核心颜色决策位于约 1.05 屏内。每档完整解释仍保留给读屏，并在颜色详情页可见。
- 320px 补充检查的 `scrollWidth` 为 320px，无页面级横向滚动。
- 375px 下执行 150% 文本放大压力检查后，`scrollWidth` 仍为 375px，“注意”底部为 1189px（约 1.46 屏），且没有小于 44 × 44px 的链接点击区域。
- 棕金文字 `#76552f` 对宣纸底 `#f2ede3` 的对比度约为 5.79:1；次要文字 `#6b6155` 对“注意”底 `#eeeae1` 的对比度约为 5.05:1，对配饰平衡叠加底色约为 4.68:1。
- 首页、完整颜色、搭配、推算依据和指定日期页面均没有小于 44 × 44px 的链接点击区域。
- 从首页点击“分享今天”后进入带当前 `fortuneDate`、`expectedContentVersion` 和 `channelId` 的分享路由，返回操作正常。
- 从首页点击“查看今日颜色”后进入同日期、同内容版本的颜色页；再点击“查看大吉穿法”后进入对应 `formulaId` 的搭配页。
- 从搭配页点击“查看方案详情”后进入相同内容版本与 `lookId` 对应的详情视图；详情页无横向滚动且链接点击区域合格。
- 完整颜色页保留三档颜色与两组“注意”；搭配页保留已审核图片及方案数据；推算依据页保留两段公开依据；指定日期页复用同一视觉系统。
- 浏览器控制台为 0 error、0 warning。

本轮证据是本地 Chrome 生产构建验收；微信内置浏览器、iPhone Safari、Android 主流浏览器及真实大字模式仍按 PRD 作为公开试用前的真机门槛，不以本地结果替代。
