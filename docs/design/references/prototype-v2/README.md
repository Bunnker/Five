## 使用边界

1. 可以参考色彩气质、卡片层级、内容密度和穿搭图片构图。
2. 页面结构、功能入口、五行结果、文案、状态和交互必须服从当前 PRD。
3. 原型中的日期、颜色、五行关系和命理结果只作为占位，不得作为测试数据或算法依据。
4. 新设计稿若与本目录冲突，以 `p0-design-brief.md` 为准。
