# 文档变更记录

## 2026-08-09

- 新增 ADR-0030：因真实数据报表是当前试用验证的高频任务，后台一级导航由“今日、日历、异常”扩为“今日、日历、数据、异常”。独立“数据”页提供最近 7 日/30 日折线、柱状和饼图；渠道饼图按可加总 PV，行为柱状只表示并列趋势而非严格漏斗；只读取真实埋点，无数据、采集未配置或聚合失败时不得填充 demo 或误导性零值。ADR-0029 的匿名、HMAC、90 日保留、退出和“分享发起不等于发送成功”边界保持不变。
- 冻结第一方匿名使用统计的 P0 契约：用户端旁路记录页面浏览、搭配查看、分享发起、海报保存请求与分享回流；服务端只保存独立 HMAC 后的浏览器随机标识，原始事件保留 90 日并支持退出。后台使用匿名浏览器口径的 PV、搭配查看率、分享发起和回流，不声称真实用户数、微信分享成功或目标平台；“今日”可保留精简摘要，完整趋势进入“数据”。
- 公开图片区移除“2 张重点参考 · 最多 1 张补充”等内部数量口径；图片加载失败时也不再向用户展示内容版本和审核流程术语。必备图、可选图与版本追踪继续保留在后台、领域模型和内部数据属性中。
- 公开分享入口改为“分享当天五行页面”：浏览器分享只携带页面标题和指定日期 URL，不再默认展示或复制长段系统文字；保留复制页面链接和日签海报作为降级方式。
- 分享链路继续收束为完整用户页与图片制品：用户页直接发起精确日期 URL 分享，微信内保留完整页面并引导右上角菜单；海报页自动创建任务，后端交付 PNG，浏览器支持时分享图片文件，否则退回指定日期 URL、下载或长按保存。普通 H5 不声称能够静默直发微信；定制微信卡片仍依赖认证公众号、JS 接口安全域名和服务端签名，真实微信与生产域名尚未验收。
- 海报渲染适配层显式兼容已发布不可变快照中的 `automatic-poster-template-v1`，映射到当前固定竖版 PNG 布局；不改写历史内容版本，新结构化内容继续使用 `poster-template-v3`。

## 2026-08-06

- 完成 ADR-0022/ADR-0026 的后端收尾：管理员初始化、登录与离线重置仅使用账号和 8–128 位密码；运行时只需 HMAC 密钥。旧 TOTP 与恢复数据原样兼容暂留但不再参与认证，新账号不再生成相关材料；离线重置在同一事务中提升凭据修订、撤销全部会话并追加安全审计。
- 新增 ADR-0027：单一维护者后台默认进入“今日”，一级导航收束为“今日、日历、异常”；月日历保留为独立入口，取代 ADR-0025 的“月历默认入口”决定。
- 新增 ADR-0028：公开用户内容改为北京时间 18:00 切换；独立 `servedFortuneDate` 负责公开内容选择，公开窗口为 `[D - 1 日 18:00, D 日 18:00)`，准备截止按生效前五小时调整为 13:00，18:00 缺少新日内容时 fail closed。
- 冻结 `AdminOperationsReadModel`、后台与公开页面共享每日展示投影、语义化订正，以及服务端按 `servedFortuneDate` 判断立即替换或固定 18:00 排期；23:00 命理 `fortuneDate`、时辰和 366 日黄金答案保持不变。
- 新增迁移 `000016_clone_legacy_public_windows_to_18h`：不改写历史不可变快照，克隆仍由活跃、排期或自动生产记录持有的 23:00 版本及其图片候选、当前选择、图片集和核对凭证，并原子迁移指针、任务、审计与缓存清理意图；含旧数据夹具的 PostgreSQL 集成检查覆盖该升级。
- 自动图片生产默认只请求 `required_primary` 与 `required_alternative`；`optional` 默认为 `not_requested` 且不形成异常。历史候选槽位允许未知，但不得按上传或完成顺序猜测。
