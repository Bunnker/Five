## V2.3 - 2026-07-26

- P0 收敛为匿名响应式网页，不开发微信小程序、原生 App、登录、支付或大师渠道系统；
- 网页端确认使用 Next.js、React 和 TypeScript；
- 后端确认使用 Node.js、TypeScript、NestJS、Fastify、PostgreSQL 模块化单体，P0 不引入 Redis、Kafka 或独立消息队列；
- 确认单人维护、大师外部核对、八个内容状态、366 日固定答案和 30 日大师复核规则；

- 公开保留“大吉、次吉、平”，把负向档合并为“注意”并提供大吉色普通配饰建议，不做吉祥物或卖货；

- 新增 P0 技术启动评审，明确接口字段、后台登录和公开上线阻塞；
- 完成 GitHub Issue #2：同步 PRD、设计修订说明、领域词汇表、文档索引和 Word 导出件到 V2.3；
