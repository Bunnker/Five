# Five

Five 是一个面向移动端 H5 与微信小程序的每日五行穿搭参考产品。P0 聚焦一个明确任务：让用户在十秒内知道今天优先穿什么、稳妥穿什么，以及哪些颜色建议减少。

## 当前状态

- 产品基线：PRD V2.2
- 发布形态：移动端 H5 + 微信小程序
- 当前阶段：技术设计、任务拆分与并行开发
- 文档语言：中文
